# FluentCraft Launcher

Лаунчер для Minecraft Java Edition с интерфейсом в стиле Windows 11 (Mica, Fluent-элементы, светлая и тёмная темы).

> 🤖 **Этот проект создан вместе с ИИ.** Код написан в диалоге с Claude (Anthropic) под руководством автора идеи.
> Проект открытый: ошибки и предложения приветствуются в Issues.

**Скачать:** готовые `.exe` (установщик и portable) лежат в разделе [Releases](../../releases).

- Сборки (instances): у каждой своя версия игры, загрузчик, моды, сохранения и настройки памяти
- Загрузчики: Vanilla, Fabric, Quilt, Forge, NeoForge
- Каталог **Modrinth** и **CurseForge**: моды, сборки, ресурспаки, шейдеры; обязательные зависимости ставятся автоматически
- Импорт готовых сборок: `.mrpack` (Modrinth) и `.zip` (CurseForge)
- **Оффлайн-аккаунты** без лицензии (UUID считается так же, как в самой игре)
- Нужная Java скачивается сама (Adoptium) под каждую версию игры

## Запуск

Нужен [Node.js](https://nodejs.org) 20 или новее.

```bash
npm install
npm start
```

### Сборка .exe

Двойной клик по **`build-exe.bat`** (или `npm run dist`). В папке `dist/` появятся:

- `FluentCraft-Launcher-Setup-<версия>.exe` — установщик (выбор папки, ярлыки на рабочем столе и в меню «Пуск»)
- `FluentCraft-Launcher-Portable-<версия>.exe` — один файл, запускается без установки

Если сборка падает с `Cannot create symbolic link`, запустите `build-exe.bat` от администратора
или включите «Режим разработчика» в параметрах Windows. Файлы не подписаны, поэтому SmartScreen
может предупредить при первом запуске: «Подробнее → Выполнить в любом случае».

Быстрая самопроверка без Electron: `npm run check`.

## Версия для разработчиков (Dev)

Отдельная редакция для отладки. Она ставится и запускается рядом с обычной: у неё свои данные
(`%APPDATA%\FluentCraft-Dev`), свой ярлык и оранжевый акцент со значком **DEV**.

```bash
npm run start:dev   # запуск из исходников
npm run dist:dev    # сборка .exe в папку dist-dev/ (или двойной клик по build-exe-dev.bat)
```

Что внутри:

- раздел **«Разработка»** в меню: диагностика системы (копируется в отчёт об ошибке), журнал сетевых запросов
  к Modrinth, CurseForge и Mojang, DevTools, быстрый доступ к папкам, очистка кэша загрузок
- журнал запуска показывает **полную команду Java** и пути к загрузчику
- `F5` / `Ctrl+R` — перезагрузка интерфейса после правки файлов в `renderer/`, `F12` или `Ctrl+Shift+I` — консоль
- в обычной версии то же самое включается переключателем **Настройки → Для разработчиков**

Сборка на GitHub: вкладка **Actions → Dev build → Run workflow** (файлы появятся в Artifacts) или тег `dev-1.0.1`
(тогда `.exe` попадут в pre-release).

## CurseForge

Modrinth работает сразу. Для CurseForge нужен бесплатный API-ключ: получите его на https://console.curseforge.com/
и вставьте в **Настройки → CurseForge**. Часть модов на CurseForge запрещает загрузку сторонними программами;
такие файлы лаунчер пытается взять напрямую с CDN, а если не выходит — покажет число недостающих файлов.

## Где что лежит

Данные лежат в `%APPDATA%\FluentCraft`: `minecraft\` (общие библиотеки и ассеты), `instances\<сборка>\` (моды, сохранения, конфиги),
`java\`, `config.json`, `accounts.json`.

## Оффлайн-аккаунты

Ник: 3–16 символов, латиница, цифры, `_`. Зайти на серверы с проверкой лицензии (`online-mode=true`) нельзя, скин не отображается.

## Структура проекта

```
main.js, preload.js        главный процесс Electron и мост в интерфейс
src/main/                  Java, загрузчики, Modrinth, CurseForge, запуск, аккаунты, сборки
renderer/                  интерфейс (HTML/CSS/JS без сборщика)
scripts/check.js           самопроверка
```
